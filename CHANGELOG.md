- Исправлен `input`: массив с ролью пользователя вместо строки, исключён `max_output_tokens` для ChatGPT.
- Добавлена диагностика кода, поля и Request ID при HTTP 400 без раскрытия секретов.
- Стандартный OpenAI API сохранил ограничение количества токенов; игровой движок и OTA не менялись.

# v1.0.15 · Исправление выбора моделей ChatGPT

- Устранено прерывание каталога моделей из-за лимита ответа в 500 КБ.
- Каталог теперь разбирается потоковым JSON-парсером, без загрузки всего ответа в память.
- Для скачивания каталога установлен независимый защитный предел 64 МБ, остальные OAuth-ответы ограничены как раньше.
- Сохранены вход через ChatGPT, выбор моделей, игровой прогресс и OTA.

# v1.0.14 · Вход через ChatGPT и выбор моделей

- Подключение через ChatGPT OAuth с отдельным разрешением использовать подписку и защищёнными токенами.
- Выбор моделей OpenAI API: Luna, Terra, Sol, Astra; список ChatGPT моделей берётся из аккаунта.
- Приоритет ChatGPT в автоматическом режиме без скрытых API-списаний.
- Сохранены игровая механика, совместимость сохранений и OTA.

# v1.0.13 · Образец игровых сцен и оформление решений

[+] **Сцены по пользовательскому эталону**: имена персонажей, жирные реплики с вертикальной линией и настоящие курсивные мысли без символов разметки
[+] **Оформление решений**: отдельные пронумерованные блоки с названием, пояснением, используемым навыком и реальным шансом броска
[+] **Цветная вероятность**: зелёная при высоком шансе, оранжевая при среднем, красная при низком
[+] **Показатели перед сценой**: имя героя, раса, уровень, текущая локация, день, опыт, масса инвентаря и септимы
[+] **Карточка текущего журнала** прямо на экране сцены, с действительными состояниями квестов и событий
[=] Для обычных действий без проверки вместо фиктивного процента показывается «Проверка навыка не требуется»

# v1.0.12 · Полноценные атмосферные сцены и диалоги

- Новый единый формат длинных сцен для одиннадцати режимов движка, с описаниями обстановки и диалогами персонажей.
- У имен говорящих акцент, реплики отдельно с отступом; названия предметов остаются интерактивными.
- ИИ-мастер перешёл на тот же стандарт, но не управляет механиками игры.
- Существующие сценарии пока дополняются общей атмосферной системой; индивидуальные варианты и последствия требуют дальнейшей работы.

# v1.0.11 · ИИ-мастер: первое внедрение

- Ролевой диалог с потоковой генерацией через Responses API, без изменения игрового состояния нейросетью.
- Шифрование личного API-ключа Android Keystore; отдельный интерфейс настройки и удаления.
- Постоянная память беседы в SQLite, привязанная к персонажу; экспорт и импорт вместе с сохранением.
- Сохранение оригинальных действий, боёв, сюжетных арок, путешествий, OTA и русской стилистики.
- Автоматический режим сейчас означает: настроенный облачный ИИ, иначе обычная офлайн-RPG. Локальный LLM и ChatGPT OAuth будут подключаться отдельно.
