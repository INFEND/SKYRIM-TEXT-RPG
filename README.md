# SKYRIM TEXT RPG

Неофициальная текстовая ролевая игра для Android на русском языке. Сюжет, тексты и интерфейс созданы для этого проекта. Не является продуктом Bethesda Softworks; источники фанатского атласа и ограничения географии описаны в docs/MAP_GEOGRAPHY.md.

## Первая версия 1.0.0

- **Оригинальная кампания «Пепельные печати»**: три главы, исследование и бой с боссом.
- Восемь регионов Скайрима, шесть рас и три класса героя.
- Тактические бои, исследования, случайные события, товары, задания, прокачка и репутация.
- Локальные автосохранения, экспорт/импорт сохранения кодом JSON.
- AMOLED-интерфейс, шесть цветовых акцентов, управление анимациями и размером шрифта.
- OTA без браузера: проверка GitHub Releases, скачивание APK, SHA-256, передача в Android Package Installer.

## Как получить APK

Вкладка **Actions → Android APK and OTA → последний успешный запуск → Artifacts → SKYRIM-TEXT-RPG-debug** содержит тестовую сборку, автоматически создаваемую при каждом изменении `main`.

**Важное различие:** тестовый debug APK не рассчитан на обновление поверх подписанного release APK. Для постоянного OTA нужно один раз настроить секрет подписи.

## Настройка release-подписи (обязательно для OTA)

Создай в репозитории **Settings → Secrets and variables → Actions** секрет с именем `SKYRIM_SIGNING_BUNDLE`. Значение: **Base64 от ZIP**, содержащего два файла в корне архива:

- `release.jks` — постоянный ключ подписи Android;
- `signing.properties` — параметры Gradle с четырьмя строками:

```properties
storeFile=release.jks
storePassword=YOUR_STORE_PASSWORD
keyAlias=skyrim
keyPassword=YOUR_KEY_PASSWORD
```

**Сохрани ключ и пароли отдельно**. Потеря ключа исключает OTA поверх уже установленных release APK. Никогда не загружай ключ в публичный GitHub. Можно использовать готовый пакет секрета, предоставленный отдельно от исходников.

После добавления секрета выполни **Actions → Android APK and OTA → Run workflow**. Workflow выпустит публичный GitHub Release `v1.0.0` с файлами:

- `SKYRIM-TEXT-RPG.apk` — подписанный APK для установки;
- `update.json` — OTA-манифест с SHA-256 и списком изменений.

Обновления выходят автоматически после изменения версии `versionCode` и `versionName` в `app/build.gradle` и push в `main` (если секрет настроен). Повторная публикация уже выпущенного тега не перезаписывает существующий релиз.

## Сборка вручную

Требуются JDK 17, Android SDK 35, Android Gradle Plugin 8.9.2, Gradle 8.11.1.

```sh
gradle :app:assembleDebug
```

Исходники: `app/src/main/java/dev/infend/skyrimtext`. Пакет: `dev.infend.skyrimtext` (minSdk 26, targetSdk 34).

## Сохранения

Прогресс хранится в Android SharedPreferences. При переходе с debug APK на release APK может потребоваться удалить тестовую сборку из-за разницы в сертификатах. Перед этим используй **Настройки → Копировать сохранение**, затем восстанови сохранение в release APK.
