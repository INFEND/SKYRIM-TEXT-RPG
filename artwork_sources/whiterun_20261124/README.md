# Вайтран · замена трёх кадров галереи (24.11.2026)

Три авторских изображения заменяют **только** кадры `04.webp`–`06.webp` в `app/src/main/assets/gallery/whiterun.zip`.

| Кадр | Имя в официальной русской локализации | Источник |
|---|---|---|
| 04 | Златолист, Ветреный район Вайтрана | `Сакура в сердце Вайтрана.png` |
| 05 | Йоррваскр | `Северный зал среди осенних гор.png` |
| 06 | Драконий Предел | `Северный зал среди гор.png` |

Это художественные интерпретации, а не точные снимки оригинальной игры: в частности, Златолист на новом кадре изображён цветущим розовым деревом, а окружающая площадь стилизована. Кадры `01`–`03` сохраняются без изменения содержимого. Архивы предназначены для скачиваемых игровых ресурсов, а не для прямого включения в облегчённый APK.

Замена выполняется скриптом `scripts/apply_whiterun_gallery_refresh.py` с проверкой всех исходных и новых кадров. Автоматизация после коммита обновлённого ZIP запрашивает повторный выпуск подписанного каталога ресурсов.
