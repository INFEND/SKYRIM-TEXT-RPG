[=] Локальный ИИ получает компактное состояние всех четырёх персонажей; отключённые и отсутствующие NPC отмечены явно. Коды личных действий распределены между персонажами, чтобы длинный список одного NPC не вытеснял остальных.
[=] Облачный ИИ получает подробные состояния Альмы, Итачи и Ливии, а не только Кэтрин.
[=] Выход из механического меню кнопкой «Назад» обновляет ИИ-сцену; повторная генерация продолжает приключение с учётом памяти.
[+] Два регрессионных теста контекста спутников.
