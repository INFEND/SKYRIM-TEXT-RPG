# Кэтрин — согласованный объём разработки

Кэтрин является самостоятельным NPC, спутницей и сюжетным персонажем. По решению пользователя от 16.11.2026 **не создавать режим новой игры за Кэтрин**. Допустим выбор её начального состояния как NPC. Использовать исключительно десять присланных изображений (см. KATHERINE_GALLERY.md); не заменять и не генерировать новые. Включать тяжёлые ресурсы только через подписанную докачку. Сохранять непротиворечивую историю с Деймоном; драконий отклик не равен доказанному драконьему происхождению. Оставшиеся приоритеты: полноценное тестирование APK, публикация оригинального архива в каталоге ресурсов, более глубокая автономность ИИ, отдельный инвентарь и расширение сюжетных развилок.
