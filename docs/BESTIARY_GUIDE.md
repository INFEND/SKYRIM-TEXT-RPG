# Бестиарий SKYRIM TEXT RPG · v1.0.303

## Объём
- 131 отдельная запись: 105 записей мира Skyrim, Dawnguard и Dragonborn, 23 авторских существа, 3 игровых архетипа противников.
- Каждая запись содержит среду обитания, внешность, поведение, сильные и слабые стороны, способности, качественную угрозу, возможную добычу и предание.
- Для авторских существ выделены типы: стайные твари, болотная нежить, трупоеды, инсектоиды, призраки, реликты, огроиды, проклятые и болотные твари.
- Названия и сведения доступны через Кодекс → Бестиарий; работают поиск и фильтры по категориям.
- В обычном и ИИ-бою можно открыть карточку противника, если его название известно справочнику.

## Достоверность и игровые ограничения
- Справочные уровни угрозы не являются числовой статистикой боевого движка.
- Возможная добыча описывает лор и потенциальные трофеи, а не гарантию выпадения из текущей системы наград.
- Авторские существа не выдаются за канонических обитателей Skyrim.
- Дублирующие/неподтверждённые записи исключены.
- Не добавлены изображения существ: графический ресурсный пакет и проверка прав на материалы остаются отдельной задачей.

## Контроль
- `BestiaryCatalogTest` проверяет полноту структуры, уникальность, категории, поиск и алиасы боевых противников.
- OTA-публикация зависит от успешного GitHub Actions `Android APK and OTA` и доступности ключа подписи.
