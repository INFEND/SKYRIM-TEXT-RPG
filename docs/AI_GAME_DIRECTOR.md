# Режим полного управления ИИ · v1.0.22

Включение «ИИ управляет всей игрой» заменяет обычную текстовую сцену
на автономный интерфейс мастера. Панели стандартного повествования,
офлайн-действий, офлайн-журнала и показателей перед сценой скрываются
из основного экрана. Карта, герой, рюкзак, настройки и системная
навигация остаются доступны на других вкладках.

## Один ответ ИИ
Генерация через существующие ChatGPT OAuth или API и потоковый Responses API.
Строго один JSON-объект, первым ключом scene, далее choices (ровно 10),
effects, journal, customChance. На экране по мере получения потока
отображается только содержимое scene, не служебный JSON.

Каждая choice: {title, detail, skill, chance}; chance целое 0..100
либо null без проверки. На экране отдельная кнопка и цветная вероятность.
Нажатие выбирает действие, а приложение генерирует случайный бросок
1..100. Бросок и исход передаются ИИ как подтверждённый факт.

Под кнопкой 10 расположено поле «СВОЙ ВАРИАНТ ОТВЕТА».
Свободное действие отправляется модели с реальным случайным броском,
модель определяет customChance и строит последствия.

## Состояние
Патчи effect применяются к копии GameEngine только после успешной
завершённой генерации, без изменения прежнего состояния при ошибке.
Доступны параметры здоровья, магии, выносливости, их максимумы,
золото, опыт/уровень, репутация, атака, броня, зелья, время,
локация атласа, инвентарь, навыки, враг, журнал и главные главы.
Проверяются пределы параметров, реальные предметы, предел 50 кг,
локации, допустимые величины дельт. Новый AI-ход сохраняется
внутри прежнего schema-1 сохранения. Старые сохранения читаются,
отключение ИИ возвращает обычную игру.

При первоначальном создании сцены эффекты игнорируются. Модель
не вправе наградить героя за один факт запуска ИИ.

## Ограничения
ИИ создаёт собственные десять вариантов и вероятности, но физический
бросок и атомарная запись игрового состояния остаются кодом Android.
Это необходимо, чтобы данные не пропадали и не повреждали сохранение.
Текст сцен, контекст последних событий и журнал ИИ доступны в памяти.
Новые предметы, которых нет в ItemCatalog, нельзя автоматически
добавить в рюкзак, пока не расширен каталог.

Дальнейшее улучшение: более тонкие системы квестов, статусы всех NPC,
неизвестные подлокации, автоматическое восстановление ответа модели
с нарушенной схемой, проверка свободного хода в два этапа
(предложенная вероятность -> бросок -> разрешение).
