# Русификация SKYRIM TEXT RPG по официальной русской локализации Skyrim

## Проверенное исходное состояние (23.11.2026)

- Интерфейс и большая часть игрового контента уже написаны по-русски, но это **не означает**, что тексты совпадают с официальной русской локализацией Bethesda/1С-Софтклаб.
- `CanonicalCampaign.java` описывает 33 этапа главной истории собственными сценами. `CanonicalCampaign.loadLocal()` уже может читать `story_core_v7.json` из assets или `imported_story_v7.json` из внутренних файлов приложения. Если корректного пакета нет, показываются **авторские реплики** из Java, не оригинальная озвучка.
- В публичном репозитории **нет** официальных русских `Skyrim_Russian.*STRINGS` и `Skyrim - Voices_ru0.bsa`; их наличие на телефоне пользователя здесь не проверялось.
- В `tools/map_names_ru.txt` есть отдельный список русских географических названий, но он не проходит автоматическую проверку по оригинальным ID. Часть названий может быть неканоничной.
- NPC, предметы, квесты, дневник, описания локаций, сторонние/авторские сцены и все дополнения требуют отдельных проверок, а не одной глобальной замены слов.

## Какие источники считать эталонными

1. Официальные русские файлы конкретной версии Skyrim из **собственной лицензионной установки**. В папке `Data/Strings` находятся `Skyrim_Russian.STRINGS`, `Skyrim_Russian.ILSTRINGS`, `Skyrim_Russian.DLSTRINGS` и файлы соответствующих дополнений. Для сопоставления названий по ID полезны парные `*_English.STRINGS`.
2. Для точных **говорящих персонажей и контекста** нужны записи INFO/QUST из `Skyrim.esm` и DLC (например, проверенный экспорт через xEdit или Creation Kit). **DLSTRINGS хранит текст, но сам по себе не доказывает, кто произнёс строку, в какой сцене и при каком условии.**
3. Если требуется именно **голосовое воспроизведение**, понадобятся законно полученные локальные русские архивы `Skyrim - Voices_ru0.bsa` и соответствующая идентификация путей/голосовых типов. Настоящая озвучка **пока не подключена**. Не выдавать авторский текст, TTS или распознавание речи за оригинальный дубляж.
4. Авторские персонажи, новые сюжетные линии и произвольные ИИ-сцены не имеют официального дубляжа. Для них применять официальный глоссарий имён и терминов, но не приписывать им несуществующие официальные реплики.

## Реализован первый технический этап: проверяемый импорт

`tools/official_ru_localization.py` поддерживает два сценария. Скрипт **не скачивает чужие ресурсы** и не добавляет защищённые тексты/аудио в публичный репозиторий.

### 1. Аудит географических названий

Указать реальную папку `Data/Strings`, в которой есть **парные** английские и русские `*.STRINGS`. Затем из корня проекта выполнить:

```sh
python3 tools/official_ru_localization.py audit-names \
  --strings-dir "/path/to/Skyrim/Data/Strings" \
  --names tools/map_names_ru.txt \
  --output "/private/place_names_audit.json"
```

В отчёте четыре статуса:

- `verified`: текущее русское название точно совпало с официальной строкой по **тому же ID**.
- `needs_review`: найдено официальное значение того же ID, но перевод проекта отличается.
- `ambiguous`: у одинакового английского имени несколько разных официальных русских значений. Контекст нужно разрешать вручную.
- `not_found`: имя не найдено среди доступных пар `STRINGS`. Это **не доказывает ошибку**: запись могла находиться в других ресурсах/типах записей.

**Никаких автоматических глобальных замен:** совпадение слова не доказывает идентичность FormID. Отчёт служит реестром ручной сверки.

### 2. Локальный пакет диалогов главной истории

Потребуется вручную проверенный manifest JSON, где каждая запись связывает ID текста с конкретным говорящим и этапом. Пример **схемы**, не реальные Skyrim ID:

```json
{
  "segments": [
    {
      "scene_id": 1,
      "source": "Skyrim",
      "speaker": "Проверенный персонаж",
      "string_id": "12345",
      "line_start": 10,
      "requires_manual_review": false,
      "exclude_from_reading": false
    }
  ]
}
```

Здесь `scene_id` от 1 до 33, `source` выбирает DLC/основную игру (например, `Skyrim`, `Dawnguard`), `string_id` есть числовой ключ официального `<source>_Russian.DLSTRINGS`. `speaker` следует сверить в INFO/QUST, **не угадывать** по тексту. `line_start` используется существующим движком для разделения реплик **до/после битвы** и ветки мирных переговоров: его нужно согласовать с порогами `CanonicalCampaign.java`. Порядок записей в массиве соответствует порядку чтения.

Manifest должен содержать хотя бы одну проверенную реплику для каждого из 33 этапов, иначе сборка пакета прекращается. Это специально предотвращает ввод частичного файла в режим «всё готово». Для примера выше команда не пройдёт валидацию до заполнения остальных этапов.

```sh
python3 tools/official_ru_localization.py build-story \
  --strings-dir "/path/to/Skyrim/Data/Strings" \
  --manifest "/private/verified_dialogue_manifest.json" \
  --output "/private/imported_story_v7.json"
```

Созданный JSON соответствует существующему `StoryDialoguePack.parse()`. В приложении открой **Настройки → Дополнения → Русская локализация → Импортировать русские диалоги** и выбери приватный `imported_story_v7.json`. Android проверит происхождение формата, структуру и полноту 33 этапов, атомарно сохранит файл в личное хранилище и сразу подгрузит реплики. После перезапуска пользовательский пакет имеет приоритет перед встроенным. В публичные коммиты/Release **не добавлять**.

В режиме `build-story` проверяются размер файла, структура, кодировка CP1251, 32-битные ID, отсутствие пустого говорящего, полнота 33 этапов и ограничение пакета 4 МиБ. Если отсутствует ID или источник, скрипт не подменяет реплику выдуманным текстом.

## Остальной объём полноценной русификации

| Категория | Текущий статус | Критерий завершения |
|---|---|---|
| Названия мест | Инструмент аудита готов; реальные файлы не предоставлены | Каждое расхождение привязано к FormID и разрешено |
| Основная кампания | Приватный импорт JSON доступен в настройках; оригинальный пакет отсутствует | 33 главы подтверждены по INFO, тексту, говорящим, развилкам |
| Побочные/фракционные задания | Не проверено | Полные названия, цели, журналы, варианты и условия |
| NPC и типовые противники | Не проверено | Имена/титулы/падежи с сохранением идентичности |
| Места, книги, предметы, магия | Не проверено | Официальные термины в каталоге, карте, инвентаре и описаниях |
| ИИ-режимы и офлайн-сцены | По-русски, но без эталонного словаря | Один проверенный глоссарий во всех провайдерах |
| Оригинальные голосовые файлы | Не интегрированы | Только локальные законно предоставленные ресурсы, синхронизация с репликой |
| Android-тестирование и релиз | Не выполнено для данного этапа | Проверка импорта на устройстве, отсутствие регрессий, CI |

**Важно:** импортёр и тесты закрывают только основу, а **не** всю локализацию. Не обозначать задачу как «100%», пока не проверены исходные файлы, соответствия ID и Android-сборка.
