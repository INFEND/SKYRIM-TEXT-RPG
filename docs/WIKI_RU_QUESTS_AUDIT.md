# Сверка названий главных заданий и совместимости поиска

Проверка по русской The Elder Scrolls Wiki:

- [На свободу!](https://elderscrolls.fandom.com/ru/wiki/На_свободу!) — английское название *Unbound*. Название первого сюжетного этапа исправлено с «На свободу» на **«На свободу!»**, включая восклицательный знак.
- [Дом Пожирателя мира (квест)](https://elderscrolls.fandom.com/ru/wiki/Дом_Пожирателя_мира_(квест)) — английское название *The World-Eater's Eyrie*. Исправлена капитализация последнего слова в названии 28-го этапа.
- [Рог Юргена](https://elderscrolls.fandom.com/ru/wiki/Рог_Юргена) — **уже правильное** название 9-го этапа. Не нужно заменять его на полное имя персонажа «Юрген Призыватель Ветра».
- [Дракон в небе](https://elderscrolls.fandom.com/ru/wiki/Дракон_в_небе) и [Проклятие Алдуина](https://elderscrolls.fandom.com/ru/wiki/Проклятие_Алдуина) — названия уже соответствуют локализации.

Остальные 33 этапа не надо автоматически считать отдельными квестами оригинальной игры: SKYRIM TEXT RPG дополнительно разделяет сюжеты на авторские сцены («Эпилог», «Возвращение рога» и т. п.). Порядок, количество этапов, маркеры прогресса и квестовые ID не меняются.

В инвентаре исправлена ещё одна совместимость: после замены на канонические названия поиск теперь находит предметы по **новому отображаемому имени и старому внутреннему ID**, одновременно сохраняя поиск по категории. Ранее поиском по старому названию нельзя было найти «Эбонитовую кирасу», когда на экране отображалась «Эбонитовая броня».

Контракты закреплены тестами `tests/test_wiki_ru_quests.py`. Сборка и Python-регрессия запускаются GitHub Actions.
