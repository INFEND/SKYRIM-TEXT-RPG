# SKY29: восстановление 29 кадров

29 исходных PNG пользователя (92 634 593 байта), 7 пакетов WebP, 29 галерей / 167 кадров. Высокий Хротгар дополнен пятью кадрами, прежние архивы сохранены. Снежная тропа относится к Глотке Мира. Проверки сжатия: полное разрешение, SSIM ≥ 0,985, блоки ≥ 0,965, контроль цветовых ошибок. Исходники и временные фрагменты не входят в main и APK. Для точных размеров см. gallery_expansion_compression.json.
