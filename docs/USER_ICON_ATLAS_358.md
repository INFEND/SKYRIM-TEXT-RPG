# Иконки из пользовательского листа, 9 ноября 2026

Источник: присланное изображение размером 1536×1024 пикселей.
Векторизовать/перегенерировать рисунки не потребовалось: контуры и светотень
взяты непосредственно из пользовательского файла.

- 358 названий в указанном пользователем порядке.
- 19 строк с НЕРАВНОМЕРНЫМ количеством символов.
- Обнаружено и индивидуально выделено 336 самостоятельных рисунков.
- В листе отсутствуют 22 отдельных рисунка; для этих названий таблица
  explicitly lists a semantically nearest reused symbol in the SAME image.
- Прозрачный PNG 1024×683 с палитрой из восьми оттенков: 106 КБ вместо 2.8 МБ.
- Точная адресация прямоугольников находится в icons/skyrim_icons_358.json.
- Два одинаковых текста «замки» разнесены: замки (для механизмов) и
  «замки (сооружения)» для крепостей. Исходный порядок обоих сохранён.
- PNG и таблица включаются непосредственно в APK; сетевой доступ не нужен.
- Иконки прорисовываются в навигации, инвентаре, навыках, кнопках ИИ и
  офлайн-сцен, а также на интерактивной карте.
- Старый атлас 48 оригинальных иконок сохранён как обратносуместимый fallback.
