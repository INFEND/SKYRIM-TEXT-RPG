# Location type icons

Six cropped and alpha-cleaned glyphs from the approved generated sheet. 3×2 cells of 96×96 pixels. Lossless grayscale WebP, 3568 bytes. Order: fort, farm, camp, giant camp, cave, standing stones. Military camps use the regular camp glyph; standing stones use the new glyph only on the Skyrim sheet. Solstheim's All-Maker Stones keep their previous mapping. Shared map and list mapping through SettlementIcons. City atlas unchanged.
