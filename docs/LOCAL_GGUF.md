# Локальный GGUF: Qwen3.5-9B

Настройки → ИИ-приключение → Локальная модель · GGUF.
В системном проводнике выбери скачанный файл .gguf из Download.
Приложение проверяет заголовок GGUF и копирует файл в свою папку.
Исходный файл сохраняется; модель не включена в APK.

Для Qwen3.5-9B Q4_K_M потребуется около 5,7 ГБ дополнительного свободного места при импорте.
PocketPal не выступает сервером для игры: приложение запускает модель отдельно.

После копирования выбери источник Локальная GGUF и включи ИИ-мастера.
Поддерживаются сцены, 10 ответов, двухэтапный расчёт риска и безопасная запись effects.
Контекст: 4096 токенов; потоки CPU: 4; лимит генерации: 2304 токена для сцен.
Используется потоковая Android-библиотека KotlinLlamaCpp 0.4.0 (llama.rn-style JNI),
поэтому слова/сцена появляются по мере генерации. Ускорение GPU в этой версии не включено. Движок работает в отдельном процессе :llm,
так что сбой native-кода не должен закрывать интерфейс игры. Отмена прерывает именно процесс
модели, не изменяя сохранения. Большой атлас и история подаются модели в сокращённом виде.
Сохранения, API и ChatGPT работают по-прежнему.
Для проверки офлайн-режима отключи интернет после установки APK и импорта модели.

## Диагностика и скорость

Открой Настройки → ИИ-приключение → ПРОВЕРИТЬ ЛОКАЛЬНУЮ МОДЕЛЬ.
Короткий тест импортированного GGUF не меняет историю и игровые сохранения.
Нативный движок сначала загружает модель в RAM, затем обрабатывает запрос и
генерирует текст на CPU. С этого обновления потоковые токены и черновик сцены
видны уже в ходе генерации; действие принимается только после готового JSON.
В тесте отображаются итоговая скорость в токенах/с и число токенов.
Обычная локальная сцена ограничена 2304 токенами, свободный диалог 768,
оценка шанса 128. Размер контекста остаётся 4096 токенов.
Через 12 минут без результата запрос завершается диагностической ошибкой
без изменения текущего сохранения. Для длинных сцен 9B CPU может быть слишком
медленным. Наличие 24 ГБ RAM не означает, что старые версии движка поддерживают Qwen3.5.
Проверка на реальном устройстве обязательна даже после успешной сборки.
