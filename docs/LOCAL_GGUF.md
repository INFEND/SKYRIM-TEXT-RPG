# Локальный GGUF: Qwen3.5-9B

Настройки → ИИ-приключение → Локальная модель · GGUF.
В системном проводнике выбери скачанный файл .gguf из Download.
Приложение проверяет заголовок GGUF и копирует файл в свою папку.
Исходный файл сохраняется; модель не включена в APK.

Для Qwen3.5-9B Q4_K_M потребуется около 5,7 ГБ дополнительного свободного места при импорте.
PocketPal не выступает сервером для игры: приложение запускает модель отдельно.

После копирования выбери источник Локальная GGUF и включи ИИ-мастера.
Поддерживаются сцены, 10 ответов, двухэтапный расчёт риска и безопасная запись effects.
Контекст: 8192 токенов; потоки CPU: 4; лимит генерации: 4096 токенов.
У бесплатной встроенной библиотеки пока нет потокового показа токенов и GPU.
Поэтому ответ появится после завершения вычисления. Отмена блокирует применение
результата, но вычисление может завершаться в фоне до освобождения ресурсов.
Сохранения, API и ChatGPT работают по-прежнему.
Для проверки офлайн-режима отключи интернет после установки APK и импорта модели.
