## Совместимость

Изменения в `ItemCatalog` выполняют замену **только отображаемого имени**. `Item.id`, ключи `items`, таблицы сохранённых количеств, закалки, экипировки и состояние квестовых предметов не меняются.

При запросе `ItemCatalog.find` по новому имени работает `DISPLAY_ALIASES` с возвратом исходного ключа. При поиске по старому имени работает прежний `items.get(id)`. Сортировка выполняется по новому отображаемому имени. **Рецепты улучшения, материал закалки и слот брони теперь определяются по неизменному `id`, а не по переведённому `name`.**

Онлайн и локальные ИИ получают дополнение к уже существующему словарю, но конкретные модели могут ошибаться; источником истины остаётся игровой каталог.

Регрессии: `python3 -m unittest discover -s tests -p 'test_wiki_ru*.py' -v`; Android: `gradle :app:assembleDebug`.

## Что остаётся вне этого пакета

Не все имена из огромных каталогов оружия, NPC, заклинаний, перков, существ, книг, квестов и локаций удалось поштучно сверить. По неподтверждённым позициям нельзя придумывать «официальный» вариант. Авторский контент сохраняет собственные названия.
