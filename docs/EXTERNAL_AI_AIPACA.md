# AiPaca: внешний локальный ИИ для SKYRIM TEXT RPG

Интеграция рассчитана на [dojekon/AIPaca](https://github.com/dojekon/AIPaca), а **не** на другой AIpaca/Firn с HTTPS:8443.

## Установка и запуск

1. Установите AiPaca отдельно от SKYRIM TEXT RPG.
2. Импортируйте совместимую GGUF-модель и загрузите её внутри AiPaca.
3. В настройках AiPaca запустите OpenAI-совместимый API-сервер на **127.0.0.1:8080**, не открывая его в локальную сеть.
4. Если сервер требует ключ, сохраните его в **Настройки → ИИ-приключение → Источник ИИ → AiPaca → API-ключ AiPaca**.
5. Нажмите **Проверить подключение AiPaca**. Эта проверка запрашивает \`GET http://127.0.0.1:8080/v1/models\` и не влияет на игровое сохранение.
6. Откройте ИИ-приключение. AiPaca используется для сцен, десяти решений, свободных реплик и коротких проверок вероятности.

## Протокол и разделение ответственности

- \`GET /v1/models\` проверяет доступность и выбирает первый загруженный ID (или \`ai_aipaca_model\`, если он уже сохранён и присутствует в списке).
- \`POST /v1/chat/completions\` передаёт массив \`messages\`, \`stream=true\` и предел выходных токенов.
- SSE \`choices[0].delta.content\` выводится постепенно, но **не** изменяет GameEngine.
- После окончания генерации \`AiGameTurn.parseLocalModel\` проверяет полный JSON из сцены и десяти вариантов. Только затем эффекты применяются к клону состояния и сохраняются.
- История ИИ общая для всех источников через существующую \`AiStoryMemory\`.

## Резерв

Если AiPaca не отвечает, отключается, прерывает поток или возвращает ошибку, игра может запустить установленный **SKYRIM Local AI Engine** и локально импортированную модель. По умолчанию резерв включён; его можно отключить в настройках AiPaca.

Резерв **не** использует ChatGPT или платный OpenAI API. Повторная генерация не перебрасывает кубики и не применяет эффекты уже выполненного действия второй раз. Кнопка «Остановить» отключает запрос и **не** вызывает резерв.

Если локальный APK движка или GGUF отсутствуют, игра показывает ошибку и сохраняет старый прогресс.

## Безопасность и ограничения

- В коде зафиксирован адрес \`127.0.0.1:8080\`. Внешние HTTP-хосты, прокси и HTTP-редиректы запрещены; \`network_security_config.xml\` разрешает cleartext только для loopback.
- API-ключ AiPaca шифруется Android Keystore отдельно от ключа OpenAI API.
- Обнаружение порта не выполняется; сервер AiPaca должен быть включён пользователем и слушать указанный адрес.
- Для запуска AiPaca на другом телефоне потребовался бы иной защищённый канал; **эта интеграция принимает только локальный сервер на том же Android-устройстве**.
- При недостаточной памяти или остановке AiPaca системой Android потребуется повторно включить сервер в AiPaca.
- Скорость и успешная генерация определяются конкретной GGUF-моделью, контекстом и настройками AiPaca; результат на физическом телефоне следует тестировать отдельно.

## Точки интеграции

- \`AiPacaClient.java\`: Chat Completions, discovery моделей, SSE, остановка, ограничение ответа.
- \`AiPacaKeyVault.java\`: отдельно зашифрованный токен сервера.
- \`MainActivity.java\`: выбор источника, диагностика, потоковый UI, безопасный резерв.
- \`AndroidManifest.xml\` + \`network_security_config.xml\`: loopback cleartext HTTP.
