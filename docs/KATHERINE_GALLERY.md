# Оригинальная галерея Кэтрин

Использовать только предоставленный архив Katherine_gallery.zip (10 WebP, 672602 байта).

SHA-256: `d68789d37c7dff7ffd8d517169b1ee974df65f56c815ef6131263e9eb6f68fa8`.

Для серверной докачки добавить файл без перепаковки в `app/src/main/assets/media/katherine/gallery.zip`. Сборщик подписанного каталога проверит контрольную сумму и учтёт 10 фотографий. До публикации возможен импорт того же архива из карточки персонажа. Изображение 01 является основным портретом; отдельная миниатюра создана из него.
