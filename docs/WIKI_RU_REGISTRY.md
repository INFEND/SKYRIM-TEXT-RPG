## Что можно проверить самостоятельно

- [Реестр сущностей, JSON в gzip](../tools/localization/registry.json.gz) содержит исходный идентификатор при наличии, постоянный ключ проекта, отображаемые имена, источники, статус, основания расхождений, псевдонимы и пути использования. Разные проектные роли с подтверждённой общей идентичностью объединены. Неоднозначные объединения остаются в очереди.
- [Доказательства и прежние написания, TSV](../tools/localization/evidence.tsv) связывают статьи русской TES Wiki и конкретные игровые или проектные идентификаторы. Где была доступна история страницы, сохранён номер редакции. Названия сверялись по справочным материалам. Оригинальные файлы STRINGS Bethesda в этом пакете напрямую не использовались.
- [Снимок игровых каталогов, TSV](../tools/localization/catalog.tsv) построен из объектов Android, включая развёрнутые каталоги и их числовые индексы. Аудитор дополнительно читает упакованные рецепты. Ссылки на технические идентификаторы, поиск и старые файлы выпусков сохраняются отдельно от подозрительных фрагментов в отображаемых строках.
- [Поведенческие тесты](../app/src/test/java/dev/infend/skyrimtext/CanonicalRussianRuntimeTest.java) обращаются к реальным объектам поиска, загрузке и повторной записи инвентаря, экипировке, диалоговым заголовкам и проверке изменений инвентаря из ответа ИИ.
- На карте 32 исправленных названия имеют историческое поисковое имя и стабильный ID. Генератор использует тот же словарь. Проверены 18 навыков, пять школ магии и 273 оригинальных ранга перков. Школа и одноимённый навык используют общую запись. Два разных перка «Полный комплект» доступны в своих деревьях по разным ID.
- В общем контексте ИИ известные участники сюжетной сцены получают имена и идентификаторы. Однозначную метку в заголовке реплики движок заменяет именем. Авторские имена и падежные формы в свободной прозе сохраняются. Нераспознанные подписи передаются в контекст следующего хода. Реальные ответы облачных и локальных моделей остаются открытой проверкой.

## Третий пакет

Подтверждены ещё 125 уникальных записей, исправлены 97 названий. Сверены отдельные тома «Песни о Пелинале», «Аргонианского доклада», «Растущей угрозы» и других серий. Заклинание «Грозовой разряд» и обучающий том имеют разные FormID. Исправлены названия оружия, ключей, парагона из Dawnguard и петли из Hearthfire.

В инвентаре и при проверке ответов ИИ доступны 1 244 привязки предметов к оригинальным FormID. Идентификаторы дополнений содержат имя мастер-файла, например `HEARTHFIRE_003011`. Книга и посох «Ваббаджек» доступны по разным идентификаторам. Тест загружает оба предмета из старого сохранения, удаляет один экземпляр книги и проверяет количества после повторной загрузки. Неоднозначное изменение инвентаря из ответа ИИ отклоняется целиком. [Книга](https://elderscrolls.fandom.com/ru/wiki/Ваббаджек_(книга)) · [посох](https://elderscrolls.fandom.com/ru/wiki/Ваббаджек_(посох)).

## Четвёртый пакет

Справочник в разделе навыков содержит 20 криков основной игры, три из Dawnguard и четыре из Dragonborn. У каждого крика сохранены три слова в игровом порядке. Десять криков, которые уже использовались в игре, учтены по одному разу. Игрок может искать по прежним названиям, русскому значению слова, драконской записи и FormID. Например, для второго слова «Огненного дыхания» подтверждена запись «Тор», а источники расходятся между «Пекло» и «Пламя». Обращение к противнику в бою получает идентификатор только при совпадении записей бестиария и персонажей.

У Крузикрела и Релоникива общий BaseID `Dragonborn:03D5B5`. Их индивидуальные RefID — `01D573` и `01D572`. Заголовок реплики с одним общим BaseID остаётся без подстановки. Сохранены географические координаты и ключи загружаемых изображений. [Тель-Митрин](https://elderscrolls.fandom.com/ru/wiki/Тель-Митрин_(здание)).

## Открытые вопросы

[Полный список оставшихся 896 записей в TSV](WIKI_RU_PENDING.tsv) содержит 831 непроверенную запись и 65 конфликтов. Для конфликта указаны причина, кандидат и доступный источник. Отдельный столбец ведёт к объявлению сущности в проекте.

Аудитор отдельно сохранил четыре проверенных совпадения в отображаемых строках. Среди них название шрифта Sovngarde, сокращённое имя Элисиф в подписи к галерее и два употребления слов «запаса сил». Если меняется сама строка, проверка повторно выводит совпадение на рассмотрение.

Список в поле `entities` можно фильтровать по `status == "unverified"` или `status == "conflict"`. В `display_literals_for_review` перечислены кандидаты для ручной проверки в отображаемых строках. Поиск совпадения в тексте сам по себе не подтверждает личность, идентификатор книги или форму названия.

- Среди оставшихся NPC есть групповые шаблоны и персонажи со спорными BaseID. В списке мест есть безымянные маркеры и несколько похожих географических объектов.
- Для ряда томов название книги в таблице предметов отличается от названия изучаемого заклинания. В реестре один исходный квест осады содержит несколько контекстных названий по сторонам и целям. Поиск в журнале открывает конкретную главу.
- Охват эффектов, болезней, благословений, божеств, служебных криков противников, сюжетных упоминаний и объектов, отсутствующих в каталогах приложения, ещё не установлен.
- Автотесты покрывают старые ключи инвентаря, экипировки, NPC и назначения карты. Проверка всех возможных пользовательских сохранений остаётся открытой.

## Воспроизведение

Обычные проверки выполняются из корня репозитория с JDK 17 и Android SDK 36.

```sh
python3 tools/localization/build_names.py --check
python3 tools/audit_localization.py --markdown
python3 tools/audit_localization.py --live --json /tmp/skyrim-ru-registry.json
python3 -m unittest discover -s tests -p 'test_wiki_ru*.py'
python3 -m unittest discover -s tests -p 'test_*.py'
gradle :app:testDebugUnitTest :app:assembleDebug
```

После внесения подтверждённых названий обновите фактический снимок и реестр.

```sh
python3 tools/localization/build_names.py
python3 tools/build_geographic_atlas.py
SKYRIM_RU_REFRESH_CATALOG=1 gradle :app:testDebugUnitTest --tests '*LocalizationCatalogTest' --rerun-tasks
python3 tools/audit_localization.py --write
python3 tools/audit_localization.py
```

## Сверка с принадлежащей владельцу копией игры

При наличии оригинальных Skyrim.esm, Update.esm, Dawnguard.esm, HearthFires.esm, Dragonborn.esm и распакованных русских таблиц STRINGS доступна прямая сверка полей FULL. Команда учитывает мастер-владельца формы и порядок переопределений. Для заданий допускается уникальный EditorID. Для слов силы отдельно читаются название FULL и локализованное значение TNAM. Результат содержит локальный список именованных форм поддерживаемых типов, идентификатор строки и мастер, из которого прочитано победившее значение. Для параметризованных названий и отсутствующих строк предусмотрены отдельные статусы.

```sh
python3 tools/localization/official_names.py --data /path/to/Data --strings /path/to/Strings --out /tmp/skyrim-official-comparison.json
```

В этой проверке исходные файлы игры отсутствовали. Чтение бинарного формата, сжатых записей, переопределений, удалённых форм и совпадающих локальных ID из разных DLC проверялось на небольших тестовых данных. В проценты выше эти тестовые данные не входят.
