## Что можно проверить самостоятельно

- [Реестр сущностей, JSON в gzip](../tools/localization/registry.json.gz) содержит исходный идентификатор при наличии, постоянный ключ проекта, отображаемые имена, источники, статус, основания расхождений, псевдонимы и пути использования. Разные проектные роли с подтверждённой общей идентичностью объединены. Неоднозначные объединения остаются в очереди.
- [Доказательства и прежние написания, TSV](../tools/localization/evidence.tsv) связывают статьи русской TES Wiki и конкретные игровые или проектные идентификаторы. Где была доступна история страницы, сохранён номер редакции. Названия сверялись по справочным материалам. Оригинальные файлы STRINGS Bethesda в этом пакете напрямую не использовались.
- [Снимок игровых каталогов, TSV](../tools/localization/catalog.tsv) построен из объектов Android, включая развёрнутые каталоги и их числовые индексы. Аудитор дополнительно читает упакованные рецепты. Ссылки на технические идентификаторы, поиск и старые файлы выпусков сохраняются отдельно от подозрительных фрагментов в отображаемых строках.
- [Поведенческие тесты](../app/src/test/java/dev/infend/skyrimtext/CanonicalRussianRuntimeTest.java) обращаются к реальным объектам поиска, загрузке и повторной записи инвентаря, экипировке, диалоговым заголовкам и проверке изменений инвентаря из ответа ИИ.
- На карте 27 новых вариантов имеют исторические поисковые имена и стабильные ID. Генератор использует тот же словарь. Для 18 навыков и 55 перков из реализованных деревьев есть подтверждения. Два разных перка «Полный комплект» доступны в своих деревьях по разным ID.
- В общем контексте ИИ известные участники сюжетной сцены получают имена и идентификаторы. Однозначную метку в заголовке реплики движок заменяет именем. Авторские имена и падежные формы в свободной прозе сохраняются. Нераспознанные подписи передаются в контекст следующего хода. Реальные ответы облачных и локальных моделей остаются открытой проверкой.

## Открытые вопросы

Список в поле `entities` можно фильтровать по `status == "unverified"` или `status == "conflict"`. В `display_literals_for_review` перечислены кандидаты для ручной проверки в отображаемых строках. Поиск совпадения в тексте сам по себе не подтверждает личность, идентификатор книги или форму названия.

- Среди оставшихся NPC есть групповые шаблоны и персонажи со спорными BaseID. В списке мест есть безымянные маркеры и несколько похожих географических объектов.
- Для ряда томов название книги в таблице предметов отличается от названия изучаемого заклинания. Для повторяемых осад фортов нужно отделить исходный квест от цели конкретной стадии.
- Точные названия рас на экране создания персонажа требуют проверки по русским игровым строкам. Полный охват слов силы, эффектов, болезней, благословений, божеств, текстовых упоминаний и объектов, отсутствующих в каталогах приложения, ещё не установлен.
- Автотесты покрывают старые ключи инвентаря, экипировки, NPC и назначения карты. Проверка всех возможных пользовательских сохранений остаётся открытой.

## Воспроизведение

Обычные проверки выполняются из корня репозитория с JDK 17 и Android SDK 36.

```sh
python3 tools/localization/build_names.py --check
python3 tools/audit_localization.py --live --json /tmp/skyrim-ru-registry.json
python3 -m unittest discover -s tests -p 'test_wiki_ru*.py'
python3 -m unittest discover -s tests -p 'test_*.py'
gradle :app:testDebugUnitTest :app:assembleDebug
```

После внесения подтверждённых названий обновите фактический снимок и реестр.

```sh
python3 tools/localization/build_names.py
python3 tools/build_geographic_atlas.py
SKYRIM_RU_REFRESH_CATALOG=1 gradle :app:testDebugUnitTest --tests '*LocalizationCatalogTest' --rerun-tasks
python3 tools/audit_localization.py --write
python3 tools/audit_localization.py
```
