# OTA transfer v1.0.66

Foreground dataSync service started only by a user action. A partial APK is stored in private filesDir/ota with an identity consisting of version, trusted URL, SHA-256 and size. Cancellation closes the active connection and preserves bytes. HTTP 206 must describe the exact remaining range; HTTP 200 restarts rather than appending incompatible bytes. A different release or APK variant clears the incompatible fragment only when explicitly started. The entire file is hashed and its Android package, version and signing certificate verified before atomic publication. Ready state is persisted; installation is a separate user action. The in-app mini panel is independent of the scrollable game heading. System notification requires the normal Android notification permission for visibility; Android/OEM can still stop a foreground service, in which case manual continuation uses the saved fragment. No automatic restart after force-stop. Device testing is still required.
