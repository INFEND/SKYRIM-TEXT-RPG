# Проверка русских названий рангов врагов

Источник для рангов бандитов: [Бандиты (Skyrim)](https://elderscrolls.fandom.com/ru/wiki/Бандиты_(Skyrim)); параллельная таблица английских рангов: [Bandits (Skyrim)](https://elderscrolls.fandom.com/wiki/Bandits_(Skyrim)). Соответствие проверено по уровням 1/5/9/14/19/25/28, а не только по созвучию перевода.

Источник для некромантов: [Селвени Нетри](https://elderscrolls.fandom.com/ru/wiki/Селвени_Нетри), таблица прогрессии некромантов по уровням.

| Внутренний ключ (сохраняется) | English | Русское название |
|---|---|---|
| Бандит | Bandit | **Бандит** |
| Бандит-изгой | Bandit Outlaw | **Разбойник** |
| Бандит-головорез | Bandit Thug | **Громила** |
| Бандит-разбойник | Bandit Highwayman | **Грабитель** |
| Бандит-грабитель | Bandit Plunderer | **Головорез** |
| Бандит-мародёр | Bandit Marauder | **Мародёр** |
| Главарь бандитов | Bandit Chief | **Главарь бандитов** |
| Ученик некроманта | Apprentice Necromancer | **Некромант-ученик** |
| Адепт некромантии | Adept Necromancer | **Некромант-адепт** |
| Некромант-мастер | Master Necromancer | **Некромант-мастер** |
| Некромант | Necromancer | **Некромант** |

Обновлены только отображаемые имена через `NpcProfiles.canonicalTemplateName`, TSV-снимок игрового каталога и записи доказательств. Идентификаторы `Profile.name`, квестовые значения, характеристики, инвентарь и сохранения не переименованы.

**Разрешён конфликт имён:** прежний алиас `Разбойник` у `Bandit Highwayman` удалён: в официальной таблице он соответствует `Bandit Outlaw`. Оба шаблона по-прежнему доступны по собственному старому ключу (`Бандит-разбойник`, `Бандит-изгой`) и английскому имени. Устаревший короткий алиас `Разбойник` теперь однозначно ведёт к официальному рангу Outlaw. Старые сохранения с неоднозначным коротким алиасом без ID необходимо разбирать отдельно; автоматическое отождествление было бы ненадёжным.

Остальные NPC, не имеющие достаточно конкретного доказательства соответствия, остаются в очереди на проверку. Запись в доказательствах не означает, что проверены все NPC оригинальной игры.
