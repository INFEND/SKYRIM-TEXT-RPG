# Постоянные ресурсы и переход на облегчённый APK

v1.0.54 — переходная сборка. Не удалять её встроенные ресурсы до установки на устройство. На первом запуске существующие галереи, карты и именной атлас копируются в filesDir/resource_store/v1 без сети; перед OTA перенос повторно проверяется. Менеджер позволяет удалять/восстанавливать файлы, а удалённые вручную пакеты не восстанавливаются самопроизвольно.

Каталог SHA-256 генерируется из точного Git-коммита и включается в подписанный APK. Скачивание идёт по фиксированному HTTPS-адресу соответствующего коммита. Неполная загрузка сохраняется отдельно; только проверенная копия атомарно заменяет рабочую.

Начиная с v1.0.56 CI публикует два подписанных APK одного выпуска. Полный остаётся стандартным полем update.json и обслуживает старые клиенты. Новый клиент выбирает thinApk только после проверки переноса текущих ресурсов; устройства с уже облегчённым APK продолжают использовать облегчённые обновления. Для ручной установки на чистое устройство рекомендуется полный APK. Если пользователь намеренно удалил ресурсы, они не препятствуют облегчённому OTA.

Для локальной сборки: python3 scripts/build_resource_catalog.py --commit $(git rev-parse HEAD), затем Gradle. Не использовать --thin в рабочей копии с незакоммиченными ресурсами. Облегчённый режим следует проверять на реальном устройстве до публикации. 

В v1.0.55 добавлены автоматическая проверка на запуске и два выключенных по умолчанию режима: обновление ранее скачанных ресурсов и докачка фото при посещении. Вручную удалённые пакеты исключаются из обеих автоматических операций.

В v1.0.56 автоматизирована проверка содержимого обоих APK и совпадения сертификатов перед публикацией. Первое OTA с этой логикой всё ещё скачивается полностью на клиентах, не знающих поле thinApk. Далее используется компактный вариант. Изменившиеся пакеты ресурсов докачиваются отдельно; бинарные патчи APK пока не реализованы.
